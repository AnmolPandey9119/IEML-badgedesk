Danger Zone

Once an event is fully over, clear its print/scan history so the system starts clean for the next event. This clears the Print Count, Scan Monitoring, and Unscanned Entries tabs (counts and history logs only). It does not delete any visitor's name, URN, organization, or other details.

⚠️ Delete Everything

Permanently deletes every visitor — name, URN, organization, print history, scan history, all of it — across the entire database. Use this only when starting a completely new event from a blank slate. There is no undo.
